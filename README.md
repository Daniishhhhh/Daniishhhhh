## Engineering focus

Computer Science undergraduate building practical AI-assisted applications: retrieval-augmented systems, workflow automation, backend services, and security-focused prototypes. I care about grounded responses, useful safeguards, and clear interfaces—not inflated claims.

**Currently exploring:** responsible AI for healthcare, LLM/RAG application patterns, automation with AI agents, and network-security tooling.

## Selected work

### [Swasthya Setu AI](https://github.com/Daniishhhhh/healthcare-ai-assistant)

Multilingual rural-healthcare assistant that combines a FastAPI service, Azure OpenAI, ChromaDB retrieval, voice interaction, and location-aware hospital discovery.<br>
`Python` `FastAPI` `Azure OpenAI` `ChromaDB` `JavaScript`<br>
**Engineering signal:** emergency-risk rules can override the model response; the project also documents confidence-aware, retrieval-grounded guidance and a no-diagnosis boundary.

### [NutriGuard Pro](https://github.com/Daniishhhhh/NutriGuard-Pro)

Nutrition and food-compliance project selected for its relevance to applied AI and full-stack product work.<br>
`AI-assisted nutrition` `Full stack`<br>
**Engineering signal:** featured as a product-oriented health and regulatory-compliance build; see the repository for its current implementation and setup.

### [AI IPS](https://github.com/Daniishhhhh/AI-IPS)

Intrusion-detection and prevention experimentation focused on network-security signals.<br>
`Python` `Network security` `Scapy`<br>
**Engineering signal:** represents the security side of my work alongside application-focused AI projects.

### [Enterprise Auth System](https://github.com/Daniishhhhh/enterprise-auth-system)

Secure-backend project centered on authentication and authorization patterns.<br>
`Backend` `Spring Security` `JWT` `RBAC`<br>
**Engineering signal:** a dedicated project for access-control architecture rather than a generic frontend demo.

### [AI Newsletter Agent](https://github.com/Daniishhhhh/ai-newsletter-agent)

n8n workflow that collects AI news, uses an LLM to summarize it, formats a weekly edition, and distributes it to subscribers.<br>
`n8n` `Groq` `SerpAPI` `Google Sheets` `Gmail`<br>
**Engineering signal:** the repository includes the importable workflow definition, making the automation inspectable and reproducible.
